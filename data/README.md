# Dataset setup

Download the **Sentiment Labelled Sentences** archive from the UCI Machine Learning Repository:

https://archive.ics.uci.edu/dataset/331/sentiment+labelled+sentences

Extract the archive so this directory contains:

```text
data/sentiment_labelled_sentences/
├── amazon_cells_labelled.txt
├── imdb_labelled.txt
└── yelp_labelled.txt
```

Each file should contain tab-separated review text and a binary label.
